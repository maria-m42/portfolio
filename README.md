# Portfolio Website

A personal developer portfolio showcasing my web development projects, UI design prototypes, and technical skill set.

**Live Site:** [https://maria-m42.github.io/portfolio/](https://maria-m42.github.io/portfolio/)

---

## Features

- **Responsive & Dark-Themed Design:** Clean, modern layout designed for seamless browsing across desktop and mobile devices.
- **Interactive Lightbox Gallery:** Dynamic image showcase featuring project previews and wireframes.
- **EmailJS Contact Form:** Functional contact form allowing direct messaging with real-time feedback.
- **Interactive Modals:** Detailed project cards with smooth UI interactions.

---

## Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Services:** EmailJS (Contact Form), GitHub Pages (Hosting)
